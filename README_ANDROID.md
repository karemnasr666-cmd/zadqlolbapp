# زاد القلوب V9 — مشروع أندرويد

هذا المشروع يحتوي ملفات النسخة التاسعة الأصلية داخل `www/` مع إعداد Capacitor وسير عمل GitHub Actions لبناء APK تجريبي.

## بناء APK عبر GitHub
1. ارفع **كل محتويات هذا المجلد** إلى مستودع GitHub (وليس ملف ZIP داخل المستودع).
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build Android APK** ثم **Run workflow**، أو انتظر انتهاء التشغيل التلقائي بعد الرفع.
4. بعد نجاح التشغيل افتح نتيجة التشغيل ثم قسم **Artifacts** ونزّل `zad-alqolob-v9-debug-apk`.
5. فك ضغط ملف Artifact لتحصل على `app-debug.apk` وثبّته على هاتف أندرويد.

## ملاحظات
- هذا مشروع بناء APK تجريبي (Debug)، وليس APK جاهزًا للتثبيت الآن.
- لم يتم تعديل محتوى تطبيق الويب الأصلي داخل `www/`.
- تنزيل نص القرآن لأول مرة يحتاج اتصال إنترنت كما هو موضح في README الأصلي.
